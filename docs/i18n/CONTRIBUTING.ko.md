# Contributing to this fork

This inherited translation describes the original OpenDesign project and has not been updated for this independent fork. To avoid giving misleading guidance about sign-in, releases, maintainers, or future plans, please use the current [CONTRIBUTING.md](../../CONTRIBUTING.md). The original project's team, programs, and roadmap do not govern this fork.

Want to help restore this translation? [Open an issue on this fork](https://github.com/andremolnar/open-open-design/issues). The original authors remain credited in the [README](../../README.md#credit-to-the-original-authors) and in Git history.
