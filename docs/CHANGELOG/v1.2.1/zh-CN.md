# 缓存项目预览 — 准备中

## 新增

- `od project thumbnail <id> --path <file.html> --out <cover.png> --json`
  可读取与界面相同、经过项目授权的截图。实时产物使用 `--live-artifact <id>`
  代替 `--path`；不会覆盖已有输出文件。

## 修复

- 项目及共享设计网格的 HTML/幻灯片封面、首页最近项目栏和编辑器项目切换器默认
  使用缓存截图，不再累积运行中的缩小页面。截图在重启后保留，源文件或本地素材
  变更后会刷新。
- 鼠标悬停或键盘聚焦持续 350 毫秒才加载实时缩小预览。离开后保留 900 毫秒重入
  宽限期，随后卸载 iframe。切换时先释放前一个预览；滚出视口、导航及切到后台也会
  释放。打开项目仍保留完整交互和动画。

## 安全

- 后台截图使用有界队列、项目文件真实路径边界、源版本检查及缓存读取授权。
  桌面渲染器在沙箱中静音运行并设有时限；先打包本地素材，不下载远程脚本/素材，
  也不使用实时项目页面的源站上下文。

## 已知限制与验证

- 新截图需要桌面渲染器。单独运行 daemon 可复用已有 PNG，但缓存缺失时显示项目
  首字母。依赖远程脚本/素材或动态请求的文档，其静态封面可能不完整。
- 另有打包问题：Next.js 在已签名应用资源内写入路由缓存，导致运行后的签名验证
  失败。本版本不修复或绕过该问题。
- 同一组 30 个合成动画项目在基线中保留 30 个空闲卡片 iframe，本次修复后为零。
  本机一次十秒热缓存 CPU/RSS 采样有所改善，但不代表 GPU 测量或普遍性能保证。
  方法、截图、回归覆盖及未执行的平台/完整测试见[验证报告](../../testing/project-previews.md)。
