# 上游动效能力与安全加固 — 准备中

## 新增

- 首页和社区在原型之后提供「动效设计」，包含 Motion Future、Product Promo、
  Showreel、UI Morph 和 Visual Lesson 五个内置示例；`@` 选择器提供动效辅助技能。
- 视频需求通过现有 HyperFrames 渲染器生成可见、可编辑的 HTML/素材和 MP4。
  交互动画保留可运行 HTML；仅选择分类不会执行只要求规划的任务。
- 动效源文件支持循环播放、本地音频同步和宿主活动状态控制。渲染检查源文件与
  输出文件的对应关系、视频可解码性及有声/静音策略；尚未解决的边界风险见下文。
- CLI 同样支持 `od project create --task-type motion-design --prompt-file brief.txt`，
  `od media scaffold` 可创建可见的 `motion-source/<id>` 源文件目录。
- 增加 Motion Anything 意图路由技能、动效规范和十个无需额外依赖的网页配方参考；
  复用现有 GSAP / web-clone 集成，不增加编辑器、自动技能安装或遥测。

## 变更

- 更新经过审阅的依赖并固定 pnpm 10.34.7，统一工作区及组装应用的依赖策略。
  Electron 45 使用 SQLite 13 的稳定 Node-API 二进制；macOS 原生文件监听避免
  文件描述符数量回归。

## 移除

- 移除远程脚本管道执行、动态求值下载的 PowerShell、绕过 TLS/沙箱检查、浮动
  版本 CLI 命令以及要求 Agent 自动安装缺失工具的指引。缺少能力时应先说明，
  安装必须单独审阅来源、版本和副作用，并获得明确批准。

## 安全

- 审计导入素材和依赖来源，验证注册表完整性及签名；可选 Python 依赖固定版本，
  并提供平台专用 wheel 哈希。受控安装禁用依赖生命周期脚本。最终 OSV 检查在
  1,225 个工作区 npm 版本和已签名 macOS 应用中的 158 个 npm 版本中均无匹配，
  但这不等于完整的安全认证。
- 构建和产物整理保留 macOS 隔离及来源属性。通过仓库部署脚本安装的本地 arm64
  应用使用 Apple Development 签名，并通过严格递归验证；未公证或公开发布安装包。

## 已知限制

- HTML 预览没有 MP4 导出或通用录制按钮。需让项目 Agent 渲染定时动效，再下载
  生成的 MP4 文件。
- 媒体读取边界及协议限制、可选脚本的破坏性参数、第三方遥测代码和许可证/声明
  问题仍待处理，详见[安全审计](../../motion-patch-security-audit-2026-10-21.md)与
  [修复报告](../../motion-dependency-remediation-2026-10-21.md)。
- 项目卡片实时预览的性能问题另见 [#16](https://github.com/andremolnar/open-open-design/issues/16)，
  本次未修复。

## 范围与发布状态

本次选择性移植上游 0.25.0 中的 [PR #8619](https://github.com/nexu-io/open-design/pull/8619)，
保留本分支的任务编排、关联代码库上下文、ComfyUI 工作流、预览返回和原生文件定位功能。
不引入新的动效遥测或无关的 Vela 安装变更；现有默认不自动回传数据的行为不变。
GSAP 运行时没有传递依赖；本分支还包括上述单独审阅的依赖修复与打包兼容性工作。
排除新增遥测不代表彻底移除了所有包含遥测的第三方代码。

此版本不包含图形化时间轴编辑器或 Remotion 适配器。用法、导出要求、隐私范围及
示例来源见[动效设计说明](../../motion-design.md)。

1.2.0 仍在准备中。这些源码说明不会发布标签、安装包、更新源或托管预览。
上游历史版本及贡献归属保持不变。
