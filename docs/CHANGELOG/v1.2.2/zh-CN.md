# 按需检查 ComfyUI — 准备中

## 修复

- **测试连接**改为读取 `/system_stats`，不再下载完整 `/object_info` 目录。
  安装大量自定义节点或模型的服务器，不会再因无关节点元数据过大而导致此轻量检查失败。
- 工作流校验和图像提交仅按所选图中不同的节点类型请求 `/object_info/{node_class}`。
  提交前仍检查模型/枚举、数值范围、必填输入及连线类型。
- 设置界面和现有 `od media comfyui` 命令共用此行为；不增加界面控件、命令参数或依赖。

## 限制

连接检查为只读，不测试 GPU 生成，也不保证特定工作流兼容。健康响应上限为 64 KiB；
节点元数据仍保留单次响应及工作流累计 8 MiB 上限。所需节点的元数据仍可能包含其模型/
枚举选项。服务器或代理必须提供健康及单节点接口；失败时不会回退到完整节点目录。

详见 [ComfyUI 配置说明](../../comfyui.md)。1.2.2 仍在准备中；这些说明不发布日期、
标签、安装包或更新源。上游历史和独立版本包保持不变。
