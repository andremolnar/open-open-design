# 原生文件管理器操作 — 准备中

## 新增

- 在**项目菜单**（`…`）的 **Connect/Manage codebase** 操作旁，选择
  **在 Finder 中显示**（macOS）、**在资源管理器中显示**（Windows）或
  **在文件管理器中显示**（Linux），定位设计项目的磁盘位置。
  最近项目侧栏、项目卡片、项目内切换器和 **Design Files → Project actions**
  都提供此操作。
- 文件和文件夹菜单提供相同操作。右键单击文件行、HTML 预览卡片、图像卡片或
  文件夹即可定位该项，而不是使用关联应用打开它。Linux 会打开所在目录，
  因为各文件管理器没有通用的项目选中命令。
- CLI 提供同一操作：
  `od project reveal <id> [--path <project-relative-path>] [--json]`。
- 守护进程根据已授权项目解析位置，包括从文件夹导入的项目。拒绝绝对路径、
  路径穿越及指向项目外部的符号链接。路径缺失、原生文件浏览器不可用或启动失败
  时会报告错误，而不是静默忽略。

## 范围与发布状态

这些操作定位的是**设计项目存储**，不是单独关联的源代码仓库。文件管理器启动
在**守护进程所在计算机**上；远程网页浏览器不能通过此操作打开自身计算机的
文件系统。现有只读查看者的菜单限制保持不变。
