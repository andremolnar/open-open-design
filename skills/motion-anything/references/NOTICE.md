## Open Design changes

- Adapted the router into a functional utility with localized catalogue metadata.
- Replaced upstream editor, canvas compositor, CLI and browser MP4 instructions
  with Open Design's actual host-stage, HTML/GSAP and desktop-export boundaries.
- Bundled MOTION-SPEC with a host-priority preface; its original body is retained.
- Packaged ten first-party web recipe guides and implementations as self-contained
  references, within OD Next's existing side-file/byte limits. Original usage
  guidance is retained; preview pages and upstream recipe manifests are not
  installation requirements. This is not the full 218-recipe skill collection.
- Reused the fork's existing eight GSAP helpers and adapted web-clone rather
  than overwriting them. GSAP skill text is MIT; that is not the GSAP runtime's
  license, which is separate. No runtime or dependency is added by this helper.
- Excluded unlicensed install-on-demand companions, bulk mixed-license recipes,
  permission-only third-party effect ports, app demonstration auto-loops, and
  the upstream editor/CLI/exporter. No telemetry or automatic installation.
